Gunslugs 3 Rogue Tactics - PortMaster testing
Porter: Pixelforge Ports (Ronax)

Game: https://www.gog.com/en/game/gunslugs_3_rogue_tactics
Package: Gunslugs3.zip (BYO data; attach the built ZIP to this post)

Install:
Update PortMaster, put Gunslugs3.zip in its autoinstall folder and open PortMaster.
Stay online for the Java 17 and Westonpack downloads if needed.
Supply gunslugs3.dat from your owned Windows build (1.0.10b).
Destination: <ports directory>/gunslugs3/gunslugs3.dat.
On muOS: <SD card>/ports/gunslugs3/gunslugs3.dat.
Download the full Windows offline installer from your GOG library, install it
on Windows or extract with innoextract, then copy the archive unchanged.
See the installed gunslugs3.md for the checksum and manual installation instructions.

Controls:
| Control | Keyboard input / action |
|---|---|
| D-pad up | UP / Up / navigate |
| D-pad down | DOWN / Down / navigate |
| D-pad left | LEFT / Left / navigate |
| D-pad right | RIGHT / Right / navigate |
| A | X / Action / confirm |
| B | UP / Up / navigate |
| X | ENTER |
| Y | Z |
| L1 | A |
| R1 | X / Action / confirm |
| L2 | F1 |
| R2 | A |
| Start | O / Options |
| Select | F1 |
| Left stick | Same directions as the D-pad |
| Select + Start | Exit; save through the game first |

Use the game's default keyboard bindings. Start sends **O** for options.
